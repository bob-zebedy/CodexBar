# CodexBar 使用指南

CodexBar 常驻 macOS 菜单栏, 不显示 Dock 图标; 启动后, 菜单栏人物图标是应用的主要入口

## 快速开始

1. 确认本机已安装并登录 Codex CLI, ChatGPT App 或 Codex App
2. 启动 CodexBar, 左键点击菜单栏图标查看账号, 额度和 Token 用量
3. 右键点击图标打开设置, 根据需要开启 Codex Hook, 通知, 阻止系统休眠和跨设备同步

应用要求 macOS 15.0 或更高版本

## 常用操作

| 操作 | 结果 |
| --- | --- |
| 左键点击菜单栏图标 | 打开或关闭主面板 |
| 右键或 `Control` + 左键点击菜单栏图标 | 打开设置, 日志和退出菜单 |
| 默认全局快捷键 `⌘⇧W` | 打开或关闭主面板 |
| `⌘,` | 打开设置窗口 |
| 主面板打开时按 `⌘L` | 打开 app-server 日志窗口 |
| 双击账号图标 | 立即刷新数据 |
| 双击账号邮箱 | 模糊或恢复邮箱显示 |
| 点击任务卡片 | 打开或关闭任务中心 |
| 点击"重置次数" | 查看手动重置机会的过期时间 |
| 悬停热力图日期 | 查看当天详细数据 |

点击主面板和侧边面板以外的区域, 或按 `Esc`, 会关闭主面板

## 菜单栏图标

人物图标表示账号状态

- 带对勾: 账号数据可用
- 带叉: 未登录, 初始化失败或当前数据不可用

开启"菜单栏额度指示"后, 图标左侧显示所选额度窗口的剩余比例; 颜色按剩余额度分档

| 剩余额度 | 颜色 |
| --- | --- |
| 80% 及以上 | 绿色 |
| 60%–79% | 蓝色 |
| 40%–59% | 黄色 |
| 20%–39% | 橙色 |
| 低于 20% | 红色 |

开启 Codex Hook 后, 图标右下角可显示任务状态: 橙色表示等待批准, 蓝色表示运行中, 绿色表示刚刚完成; 多个状态同时存在时, 等待批准优先于运行中, 运行中优先于刚完成

将鼠标停在图标上, 可以查看账号异常, 任务状态, 任务时长和所选额度窗口的摘要

## 主面板

### 账号与刷新

账号卡片显示账号邮箱或名称, 订阅类型和刷新状态; CodexBar 默认每 60 秒刷新一次账号, 额度和 Token 用量; 底部圆环显示下一次刷新进度

状态含义

- "未登录": 当前 Codex 没有可用登录账号
- "初始化失败": 无法找到, 启动或连接本机 Codex app-server
- "暂无数据": 账号有效, 但当前没有额度或用量数据
- 内容变淡: 当前显示的是前一次成功读取的缓存数据

### 额度与重置机会

每个额度窗口显示名称, 剩余比例和重置时间; 一个账号可以同时返回多个额度限制和多个时间窗口

账号存在可用的手动重置机会时, 额度区会显示"重置次数"; 侧边面板按过期时间汇总这些机会; 查询不到过期时间时仍保留可用次数; CodexBar 只展示信息, 不执行重置操作

### Token 用量

用量区显示

- 全时累计 Token
- 单日峰值
- 当前连续使用天数
- 最长连续使用天数
- 最长任务时长
- 近 30 周日历热力图

热力图颜色深浅按当前可见范围内的 Token 峰值计算; 开启 Codex Hook 后, 日期详情还会显示会话, 轮次, 工具调用, 权限请求, 上下文压缩, 子 Agent 和常用模型等工作流统计

### 任务卡片与任务中心

任务卡片需要同时开启"CodexBar Hook"和"主面板任务中心"; 卡片显示当前最重要的任务状态, 以及项目, 模型, 推理强度, 工具, 时长和子 Agent 数量等可用信息

点击卡片打开任务中心, 可查看

- 等待确认的任务
- 正在运行的任务
- 最近 10 分钟内完成的任务
- 最近 10 分钟内终止的任务

只有 Codex 将审批明确路由给用户时, 任务才显示为等待批准; 自动审核和 guardian subagent 审批不会进入用户等待状态

### 底部状态

底部显示数据更新时间, 自动刷新倒计时, 同步状态和可用更新; 悬停 iCloud 图标可查看同步说明; 双击更新提示可开始安装更新

## 设置

### 通用

- 开机自动启动
- 自动检查更新
- 菜单栏额度指示及额度窗口选择
- 全局快捷键

全局快捷键默认是 `⌘⇧W`; 录制快捷键需要至少两个修饰键; `⌘Space` 和 `⌘Tab` 不可使用; 要更换已有快捷键, 先清除, 再录制新组合

### 高级

#### CodexBar Hook

开启后, CodexBar 在当前 `CODEX_HOME` 的 `hooks.json` 中注册十类工作流事件, 并通过 app-server 验证和维护对应信任状态; 关闭时只移除属于当前 CodexBar 可执行文件的配置, 不修改其他 Hook

Hook 提供实时任务, 任务中心, 工作流统计, 任务通知, 阻止系统休眠和跨设备同步所需的数据; 详细说明见 [Codex Hook 与工作流统计](CodexHook.md)

#### 系统通知

首次开启时需要允许 macOS 通知权限; 通知选项包括

- 任务完成: 任务达到 30 秒, 1 分钟, 2 分钟或 5 分钟后提醒
- 任务等待: 任务等待用户批准时提醒
- 额度预警: 剩余额度到达 5%, 10% 或 25% 时提醒
- 额度重置: 已消耗的额度窗口恢复为 0% 使用量时提醒
- 重置临期: 手动重置机会过期前 7 天至 1 天每天提醒一次
- 任务触觉反馈
- Codex TUI 通知开关

每类系统通知都可以单独选择默认声音, 静音或随应用提供的提示音; 点击通知会打开 CodexBar 主面板

#### 阻止系统休眠

该功能依赖 Codex Hook 和 macOS 后台项目授权; 只有存在运行中的任务时才阻止休眠; 任务等待批准, 全部结束, Hook 关闭, 功能关闭或达到最长时限后会恢复原系统设置

最长时限可选 1, 2, 4, 8, 12, 24 小时或无限制, 默认 12 小时; 新任务开始或等待批准后恢复运行时重新计时

首次开启后如果显示"需要授权允许 CodexBar 后台运行", 点击"打开系统设置", 在"登录项与扩展"中允许 CodexBar; 详细说明见 [阻止系统休眠](KeepAlive.md)

#### 跨设备同步

跨设备同步要求

- CodexBar Hook 已开启
- 已开启"跨设备同步"
- 当前 iCloud 账号可用

同步使用应用的 CloudKit 私有数据库, 只上传每日聚合; 开启后会补传本机保留范围内尚未确认的聚合数据; 详细说明见 [跨设备同步](CrossDeviceSync.md)

#### 重建数据

"重建数据"从本机原始 Hook 事件重新生成所选日期的每日统计; 日期范围限制在最近 210 天, 实际只处理存在非空事件文件的日期

如果跨设备同步已开启, 重建后的当前设备聚合会在后续同步中替换对应日期的旧云端记录; 其他设备的数据不受影响

### 关于

"关于"页显示

- 全局 Codex CLI 与 App 内置 Codex 的版本和路径
- 当前 app-server 实际使用的 Codex
- CodexBar 版本和更新状态
- 检查更新与退出操作

点击 Codex 路径可以复制完整路径

## 日志

日志窗口记录本次运行期间最近 500 条 app-server 请求, 响应和错误; 列表可以展开, 完整内容支持 JSON 格式化预览和复制; 点击"清空"只清除内存中的交互日志

日志不包含 Hook 原始事件, 也不会上传到 CloudKit

## 常见问题

### 显示"未登录"

在 Codex CLI 或 Codex App 中完成登录, 然后双击账号图标刷新

### 显示"初始化失败"

打开设置的"关于"页, 确认至少存在一个可用 Codex 路径, 并在日志中查看 `initialize` 或 `account/read` 错误

### Hook 开启失败

确认当前 `CODEX_HOME` 可写, `hooks.json` 是有效 JSON, 且 Codex 配置没有全局关闭 Hook; 设置页会显示验证结果

### 同步不可用

确认系统已登录 iCloud, CloudKit 账号可用且 CodexBar Hook 已开启; 同步错误会显示在主面板底部 iCloud 图标的说明中

### 阻止系统休眠未生效

确认 Hook 已开启, 当前确实有运行中的任务, 最长时限未到, 并在系统设置中允许 CodexBar 后台项目

### 菜单栏没有额度条

确认"菜单栏额度指示"已开启, 且所选额度窗口当前有数据; 主面板可同时显示多个窗口, 菜单栏只显示选中的一个

## 数据范围

账号, 额度, Token 用量和认证文件只在本机处理; Hook 原始事件和每日聚合默认保存在

```text
~/Library/Application Support/CodexBar/HookEvents/
```

跨设备同步只上传每日统计字段, 不上传原始事件, 会话 ID, 轮次 ID, 请求日志或认证文件
