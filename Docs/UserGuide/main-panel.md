# 主面板与菜单栏

简体中文 | [English](../en/UserGuide/main-panel.md)

## 菜单栏图标

CodexBar 用人物图标和可选额度圆弧表达账户、任务和额度状态：

| 外观 | 含义 |
| --- | --- |
| 普通人形 | 默认或空闲状态 |
| 斜杠人形 | 未登录、初始化失败或缺少可信额度与用量数据 |
| 时钟徽章 | 至少有一个任务正在运行 |
| 钥匙徽章 | 至少有一个任务正在等待用户批准 |
| 盾牌勾徽章 | 任务刚刚完成，显示 10 秒 |
| 盾牌感叹号徽章 | 任务刚刚被终止，显示 10 秒 |
| 人物上方的缺口圆弧 | 所选额度窗口的剩余比例，颜色与面板百分比一致 |

多个状态同时存在时，账户异常优先，其次是等待批准、运行中，最后是最近 10 秒内的完成或终止；两种结束记录按时间选择最新的一条。

隐藏额度圆弧时，人物图标会放大。

鼠标悬停在菜单栏图标上可以查看当前任务状态、项目名、持续时间、并发任务数量和额度窗口剩余比例。

显示缓存额度时，图标和圆弧变淡。额度为零时保留底轨；没有额度数据或关闭显示时隐藏圆弧。

## 自定义布局

在 `设置 > 通用 > 主面板布局` 中调整区域顺序和显隐，支持撤销与重做。具体操作见 [设置参考](settings.md#主面板布局)

## 账户区域

- 展示当前登录账户或账户类型
- 展示 Enterprise, Team, Business, Pro, Plus, Edu 和 Free 等套餐标识
- 双击账户图标会立即刷新账户、额度和用量
- 双击邮箱会切换模糊显示
- 未登录时显示 `未登录`
- 当前 Codex 版本低于要求时显示最低版本提示
- Codex 连接无法初始化时显示 `初始化失败`

具体连接失败原因可在设置的关于页面查看，完整请求和响应可在日志窗口查看。

## 额度区域

CodexBar 会展示 Codex 返回的全部额度分组和窗口。

每个额度窗口包含以下信息：

- 窗口名称，例如 `5 Hours` 或 `Weekly`
- 剩余比例
- 分段进度条
- 下一次重置时间

开启 `动画效果` 时，分段进度条会在每次打开主面板时从零填充到当前剩余比例。

玻璃分割线的渐变会缓慢流动，独立于 `动画效果` 开关；所在窗口隐藏后暂停。

主额度分组还可能展示以下信息：

- 可用积分或无限积分状态
- 可用留存重置
- 每批留存重置的过期时间

点击 `留存重置` 可查看各批次的过期时间，入口只在可用次数大于 `0` 时显示。

## Token 用量与热力图

账户用量来自 app-server，汇总区域会展示以下指标：

- 全时累计 Token
- 单日 Token 峰值
- 当前连续使用天数
- 最长连续使用天数
- 最长任务时长

热力图按日期展示近期每日 Token 用量，颜色强度相对于当前热力图中的峰值计算。

开启 `动画效果` 时，日期方块会在每次打开主面板时从左上到右下依次展示。

悬停日期方块时会显示日期、Token 数量和用量强度。

进阶模式开启时，日期详情还会显示以下统计：

- 最常用模型
- 会话数
- 对话轮次
- 子 Agent 数
- 工具调用次数
- 权限请求次数
- 上下文压缩次数

日期详情按活动统计和 rollout 日 Token 用量分组展示，并通过强度条表示当日用量强度。Token 指标包括总量、输入输出、缓存使用和推理输出等。Token 数量使用 K/M/B 缩写，缺失计数和零值均显示 `0`，缺失或为零的缓存命中率显示 `0%`。切换日期时，活动统计、Token 数字和最常用模型使用滚动切换动画。

每个线程轮次只计一次，主 Agent 和子 Agent 的用量归到根任务开始日期，跨午夜也不拆分。缓存命中率用当日缓存命中总量除以输入总量计算。启用 iCloud 同步后，各 Mac 的同一轮记录先去重再汇总。

热力图颜色、日期标题旁的 Token 数量和用量强度来自 app-server，右栏会话 Token 来自本地 rollout 及 iCloud 历史，两者的来源和统计范围不同。历史回放、续读和重建方式见 [数据、同步与隐私](sync-data-privacy.md#历史-token-回放)

## 活动卡片

活动卡片优先显示等待批准，其次是运行中任务。没有活跃任务时，显示结束时间最新的完成或终止记录；时间相同优先显示终止。

卡片会按实际可用字段展示以下内容：

- 项目名
- 模型和推理强度
- 当前工具或执行阶段
- 已运行或已等待时间
- 活跃子 Agent 数
- 其他并发任务数
- 匿名任务图标

防睡眠实际生效时，活动卡片右侧显示青绿色太阳徽标，悬停可查看防睡眠来源。开启“动画效果”时徽标持续旋转，关闭时静态显示。

无法识别会话的任务带有橙色匿名图标，悬停显示 `匿名任务不参与防睡眠`

活动卡片的 `+N` 表示其他活跃任务总数。

点击有内容的活动卡片可以打开任务中心。活动卡片和任务中心的状态文字颜色随任务状态变化。开启“动画效果”时，运行状态文字播放扫光，等待批准文字周围显示橙色粒子；关闭后保留静态彩色文字。

### 本轮 Token 用量

活动卡片取得本轮 rollout 用量后，在状态下方展示 Token 总量、输入输出、缓存使用和推理输出等指标，数量使用 K/M/B 缩写。用量区域和上方分割线一起展开或收起，动画不受 `动画效果` 开关控制。没有用量时隐藏整个区域。

运行中和等待批准时，已能确认归属的主线程与子 Agent 用量会持续更新；后续线程记录到达后继续补齐。完成或终止后会短暂补读本轮用量，取得完整汇总后显示。之后读取暂时失败时，保留已经取得的结束用量。这里统计的是当前对话轮次及其子 Agent，而非整个会话。

总量等于输入加输出；缓存命中和缓存写入包含在输入中，推理输出包含在输出中，不能再次加到总量上。缓存命中率为缓存命中除以输入；输入为零时，卡片显示 `—`。英文标签 `Cached`、`Cache-W` 和 `Cache-H` 分别表示缓存命中、缓存写入和缓存命中率。

## 任务中心

任务中心按状态分组展示以下内容：

- 等待确认
- 运行中
- 最近完成
- 最近终止

最近完成和最近终止记录保留 10 分钟。完成表示一轮任务结束，不代表执行成功；终止记录包括中断及其他终止情况，不触发完成通知。

最近完成和最近终止条目在有用量数据时显示本轮总 Token，使用 K/M/B 缩写。运行中和等待批准条目只显示任务状态；主面板活动卡片显示当前摘要任务的用量。

## 底部状态

主面板底部包含以下信息：

- 数据更新时间
- 距离下一次自动刷新的倒计时
- iCloud 同步关闭、同步中、已同步或失败状态
- 可用更新提示

发现新版本时，双击更新提示可以开始更新。
