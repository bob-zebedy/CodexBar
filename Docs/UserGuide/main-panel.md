# 主面板与菜单栏

简体中文 | [English](../en/UserGuide/main-panel.md)

## 菜单栏图标

CodexBar 用人物图标和可选额度圆弧表达账户、任务和额度状态：

| 外观 | 含义 |
| --- | --- |
| 普通人形 | 默认或空闲状态 |
| 斜杠人形 | 未登录、初始化失败或缺少可信额度与用量数据 |
| 时钟徽章 | 至少有一个任务正在运行 |
| 钥匙徽章 | 至少有一个任务正在等待用户批准 |
| 盾牌勾徽章 | 任务刚刚完成，显示 10 秒 |
| 盾牌感叹号徽章 | 任务刚刚被终止，显示 10 秒 |
| 人物上方的缺口圆弧 | 所选额度窗口的剩余比例，颜色与面板百分比一致 |

多个状态同时存在时，账户异常优先，其次是等待批准、运行中，最后是最近 10 秒内的完成或终止；两种结束记录按时间选择最新的一条。

隐藏额度圆弧时，人物图标会放大。

鼠标悬停在菜单栏图标上可以查看当前任务状态、项目名、持续时间、并发任务数量和额度窗口剩余比例。

显示缓存额度时，图标和圆弧变淡。额度为零时保留底轨；没有额度数据或关闭显示时隐藏圆弧。

## 自定义布局

在 `设置 > 通用 > 主面板布局` 中调整区域顺序和显隐，支持撤销与重做。具体操作见 [设置参考](settings.md#主面板布局)

## 账户区域

- 展示当前登录账户或账户类型
- 展示 Enterprise, Team, Business, Pro, Plus, Edu 和 Free 等套餐标识
- 双击账户图标会立即刷新账户、额度和用量
- 双击邮箱会切换模糊显示
- 未登录时显示 `未登录`
- 当前 Codex 版本低于要求时显示最低版本提示
- Codex 连接无法初始化时显示 `初始化失败`

具体连接失败原因可在设置的关于页面查看，完整请求和响应可在日志窗口查看。

## 额度区域

CodexBar 会展示 Codex 返回的全部额度分组和窗口。

每个额度窗口包含以下信息：

- 窗口名称，例如 `5h` 或 `7d`
- 剩余比例
- 分段进度条
- 下一次重置时间

开启 `动画效果` 时，分段进度条会在每次打开主面板时从零填充到当前剩余比例。

主额度分组还可能展示以下信息：

- 可用积分或无限积分状态
- 可用留存重置
- 每批留存重置的过期时间

点击 `留存重置` 可查看各批次的过期时间，入口只在可用次数大于 `0` 时显示。

## Token 用量与热力图

汇总区域会展示以下指标：

- 全时累计 Token
- 单日 Token 峰值
- 当前连续使用天数
- 最长连续使用天数
- 最长任务时长

热力图使用 30 列乘 7 行方块展示近 30 周每日 Token 用量，颜色强度相对于当前热力图中的峰值计算。

开启 `动画效果` 时，日期方块会在每次打开主面板时从左上到右下依次展示。

悬停日期方块时会显示日期、Token 数量和用量强度。

CodexBar Hook 开启且当天有数据时，日期详情还会显示以下统计：

- 最常用模型
- 会话数
- 对话轮次
- 子 Agent 数
- 工具调用次数
- 权限请求次数
- 上下文压缩次数

## 活动卡片

活动卡片的状态优先级为等待批准、运行中、最近完成、最近终止。

卡片会按实际可用字段展示以下内容：

- 项目名
- 模型和推理强度
- 当前工具或执行阶段
- 已运行或已等待时间
- 活跃子 Agent 数
- 其他并发任务数
- 匿名任务图标

防睡眠实际生效时，活动卡片右侧显示持续旋转的青绿色太阳徽标，悬停可查看防睡眠来源。

无法识别会话的任务带有橙色匿名图标，悬停显示 `匿名任务不参与防睡眠`

活动卡片的 `+N` 表示其他活跃任务总数。

点击有内容的活动卡片可以打开任务中心。

## 任务中心

任务中心按状态分组展示以下内容：

- 等待确认
- 运行中
- 最近完成
- 最近终止

最近完成和最近终止记录保留 10 分钟。完成表示一轮任务结束，不代表执行成功；终止表示被中断，不触发完成通知。

## 底部状态

主面板底部包含以下信息：

- 数据更新时间
- 距离下一次自动刷新的倒计时
- iCloud 同步关闭、同步中、已同步或失败状态
- 可用更新提示

发现新版本时，双击更新提示可以开始更新。
