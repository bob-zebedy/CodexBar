# 主面板与菜单栏

简体中文 | [English](../en/UserGuide/main-panel.md)

## 菜单栏图标

CodexBar 用图标、状态点和可选额度条同时表达账户、任务和额度状态：

| 外观 | 含义 |
| --- | --- |
| 正常账户图标 | 账户数据可用 |
| 错误账户图标 | 未登录、初始化失败或缺少可信额度与用量数据 |
| 蓝色状态点 | 至少有一个任务正在运行 |
| 橙色状态点 | 至少有一个任务正在等待用户批准 |
| 绿色状态点 | 任务刚刚完成，高亮持续 30 秒 |
| 图标旁额度条 | 所选额度窗口的剩余比例 |

多个状态同时存在时，等待批准优先于运行中，运行中优先于最近完成。

鼠标悬停在菜单栏图标上可以查看当前任务状态、项目名、持续时间、并发任务数量和额度窗口剩余比例。

额度数据来自缓存时，图标和进度条会降低透明度，表示当前看到的不是最新快照。

## 自定义布局

在 `设置 > 通用 > 主面板布局` 中，可以拖动调整 `账户`、`任务`、`额度`、`用量` 和 `状态` 5 个区域的顺序，也可以分别控制是否显示。

主面板至少保留一个区域。Hook 未开启时，`任务` 区域自动关闭且开关置灰，但仍可拖动调整位置；如果该区域原本是唯一显示区域，`账户` 区域会自动开启。重新开启 Hook 后，可以再手动开启 `任务` 区域。拖拽排序或切换区域显隐后，可以使用 `⌘Z` 按操作顺序撤销，并使用 `⌘⇧Z` 重做。

## 账户区域

- 展示当前登录账户或账户类型
- 展示 Enterprise, Team, Business, Pro, Plus, Edu 和 Free 等套餐标识
- 双击账户图标会立即刷新账户、额度和用量
- 双击邮箱会切换模糊显示
- 未登录时显示 `未登录`
- app-server 无法初始化时显示 `初始化失败`

主面板只展示适合用户判断的状态，具体请求错误保留在日志窗口。

## 额度区域

CodexBar 会展示 Codex 返回的全部额度分组和窗口。

每个额度窗口包含以下信息：

- 窗口名称，例如 `5h` 或 `7d`
- 剩余比例
- 分段进度条
- 下一次重置时间

开启 `动画效果` 时，分段进度条会在每次打开主面板时从零填充到当前剩余比例。

主额度分组还可能展示以下信息：

- 可用积分或无限积分状态
- 可用手动重置次数
- 每批重置次数的过期时间

点击手动重置次数可以打开详情面板，只有 Codex 返回可用次数时才会显示这个入口。

## Token 用量与热力图

汇总区域会展示以下指标：

- 全时累计 Token
- 单日 Token 峰值
- 当前连续使用天数
- 最长连续使用天数
- 最长任务时长

热力图使用 30 列乘 7 行方块展示近 30 周每日 Token 用量，颜色强度相对于当前热力图中的峰值计算。

开启 `动画效果` 时，日期方块会在每次打开主面板时从左上到右下依次展示。

悬停日期方块时会显示日期、Token 数量和用量强度。

CodexBar Hook 开启且当天有数据时，日期详情还会显示以下统计：

- 最常用模型
- 会话数
- 对话轮次
- 子 Agent 数
- 工具调用次数
- 权限请求次数
- 上下文压缩次数

## 活动卡片

活动卡片的状态优先级为等待批准、运行中、最近完成、最近终止。

卡片会按实际可用字段展示以下内容：

- 项目名
- 模型和推理强度
- 当前工具或执行阶段
- 已运行或已等待时间
- 活跃子 Agent 数
- 其他并发任务数
- 匿名任务图标

防睡眠实际生效时，活动卡片右侧会显示咖啡杯标记。

Hook 事件缺少 session ID 时，任务仍会显示在活动卡片和任务中心，并带有橙色匿名图标。悬停图标会显示 `匿名任务不参与防睡眠`

活动卡片的 `+N` 只表示其他活跃任务总数，不拆分匿名任务数量。

点击有内容的活动卡片可以打开任务中心。

## 任务中心

任务中心按状态分组展示以下内容：

- 等待确认
- 运行中
- 最近完成
- 最近终止

最近完成和最近终止记录在任务中心保留 10 分钟，完成与终止是不同状态。

完成表示一轮任务已经结束，不代表执行结果一定成功。

终止不会触发任务完成通知。

匿名任务在运行中、等待批准、最近完成和最近终止状态下都会显示同一个匿名图标。

## 底部状态

主面板底部包含以下信息：

- 数据更新时间
- 距离下一次自动刷新的倒计时
- iCloud 同步关闭、同步中、已同步或失败状态
- 可用更新提示

发现新版本时，双击更新提示可以开始更新。
