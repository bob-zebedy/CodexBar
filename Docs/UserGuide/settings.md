# 设置参考

简体中文 | [English](../en/UserGuide/settings.md)

右键或 Control 点击菜单栏图标并选择 `设置`，或按 `⌘,` 打开设置窗口。

设置窗口包含 `通用`、`高级` 和 `关于` 三个页面。

## 通用设置

| 设置 | 作用 | 默认或初始状态 |
| --- | --- | --- |
| 主面板布局 | 调整主面板 5 个区域的顺序和显隐 | 账户、任务、额度、用量、状态；Hook 未开启时任务关闭 |
| 动画效果 | 每次打开主面板时播放额度条填充和用量热力图波动动画 | 开启 |
| 开机自动启动 | 通过 macOS 登录项自动启动 CodexBar | 跟随当前系统登录项状态 |
| 自动检查更新 | 由 Sparkle 定期检查可用更新 | 跟随 Sparkle 当前设置 |
| 菜单栏额度指示 | 在菜单栏图标旁显示所选额度窗口剩余比例 | 主额度 |
| 全局快捷键 | 在任意 App 中打开或关闭 CodexBar 主面板 | `⌘⇧W` |

### 菜单栏额度指示

- 可在当前 Codex 返回的额度窗口之间选择
- 关闭前会记住最后选择的窗口
- 再次开启时恢复上次选择
- 缓存额度会降低显示透明度

### 主面板布局

点击设置行右侧的选项按钮，可以配置 `账户`、`任务`、`额度`、`用量` 和 `状态` 5 个区域：

- 拖动区域调整显示顺序
- 使用开关控制区域是否显示
- 至少需要保留一个区域
- 拖拽排序或切换显隐后，可以使用 `⌘Z` 按操作顺序撤销，并使用 `⌘⇧Z` 重做

`任务` 区域与 CodexBar Hook 联动。Hook 未开启时，该区域自动关闭，其开关置灰且无法开启，但仍可拖动调整位置。重新开启 Hook 后，该区域保持关闭，可以再手动开启。

隐藏区域只影响主面板展示，不会停止额度刷新、Hook 统计、通知、防睡眠或同步。

### 全局快捷键

- 录制结果至少需要两个修饰键
- `Command-Space` 和 `Command-Tab` 等系统保留组合不可使用
- 已被其他 App 占用的组合会提示冲突
- 可以清除快捷键
- 可以恢复默认值 `⌘⇧W`

## 高级设置

| 设置 | 作用 | 默认状态 |
| --- | --- | --- |
| CodexBar Hook | 安装并校验 Codex 事件 handler | 未安装时关闭 |
| 系统通知 | 控制 CodexBar 本地通知和任务触觉反馈 | 关闭 |
| 自动重置 | 按所选提前量在过期前使用尚未消费的重置次数重置 Codex 额度 | 关闭，提前 30 分钟 |
| 防止系统睡眠 | 根据实时 Codex 任务自动切换系统睡眠 | 关闭 |
| 跨设备同步 | 通过 iCloud 同步每日 Hook 聚合 | 关闭 |
| 重建数据 | 从所选日期的本机原始事件重新生成聚合 | 手动操作 |

### CodexBar Hook

开启后解锁实时任务、任务类通知、Hook 统计、防睡眠和跨设备同步。

开启和校验要求当前 app-server 为 `0.145.0` 或更高版本。

完整说明见 [实时任务与 CodexBar Hook](activity-and-hook.md)

### 系统通知子选项

| 选项 | 默认值 | 其他可选值或说明 |
| --- | --- | --- |
| 任务完成通知 | 开启，1 分钟 | 最短时长可选 30 秒, 1, 2, 5 分钟 |
| 任务等待通知 | 开启 | 需要 CodexBar Hook |
| 额度预警通知 | 开启，10% | 阈值可选 5%, 10%, 25% |
| 额度重置通知 | 开启 | 只在观察到消耗后识别重置 |
| 重置临期通知 | 开启 | 提醒 7 天内到期的手动重置次数 |
| 自动重置通知 | 开启 | 只有自动重置开启时可用，成功和失败共用音效 |
| 低电量保护通知 | 开启 | 只有低电量保护实际可用时生效 |
| 防睡眠上限通知 | 开启 | 只有最长时间不是无限制时生效 |
| 任务触觉反馈 | 关闭 | 任务完成或等待批准时触发触摸板震动 |
| Codex TUI 通知 | 跟随 Codex 配置 | 独立于 CodexBar 通知 |

每类系统通知可以选择默认、静音、系统声音或 App 内置声音。

完整说明见 [通知与提醒](notifications.md)

### 自动重置与防睡眠开启确认

`自动重置` 和 `防止系统睡眠` 每次从关闭切换为开启时都会显示确认框。确认框先按 CodexBarHelper 当前状态显示提示，再显示对应功能说明：

| CodexBarHelper 状态 | 确认提示 |
| --- | --- |
| 未注册或文件缺失 | `需要安装并授权 CodexBar Helper 后台运行` |
| 已安装但等待系统批准 | `已安装 CodexBar Helper 但需要授权允许后台运行` |
| 已安装并获得系统批准 | 只显示对应功能说明 |

对应功能说明为：

| 功能 | 确认标题 | 功能说明 |
| --- | --- | --- |
| 自动重置 | `开启自动重置?` | `开启后, CodexBar 在手动重置临近过期时, 按设置的临期时间提前自动使用重置; 并可能短暂唤醒 Mac` |
| 防止系统睡眠 | `开启防止系统睡眠?` | `开启后, CodexBar 会在 Codex 任务运行时防止系统睡眠, 任务结束后自动恢复` |

选择 `开启` 后保存开关状态并尝试注册 CodexBarHelper；选择 `取消` 时开关保持关闭。这两个功能的 Helper 授权系统设置只通过已开启设置行下方的 `打开系统设置` 按钮打开，该按钮在 CodexBarHelper 等待系统批准时显示。两个开关处于关闭状态时，设置行下方不显示状态说明。

### 自动重置

自动重置开关已开启且 CodexBarHelper 已安装并获得系统批准时，主开关行右侧显示选项按钮。点击后可在侧边面板的“临期时间”中选择到期前 `15 分钟`、`30 分钟`、`1 小时`、`2 小时`、`4 小时` 或 `6 小时` 开始尝试，默认是 `30 分钟`。Helper 状态不满足条件时入口隐藏，已展开的自动重置面板会关闭。

- 只处理 app-server 最新响应明确列出的可用重置次数
- 每次使用前重新确认账号、凭证状态和过期时间
- 同一时间只处理最早到期的一次
- 确认开启后会尝试注册 CodexBarHelper；即使“防止系统睡眠”关闭，也可能需要在“登录项与扩展”中批准 CodexBar 后台运行
- 自动重置设置行会显示 CodexBarHelper 待批准、未注册、注册失败或唤醒计划同步失败状态
- 有未来任务时，CodexBarHelper 只为最近一次阈值或重试注册一个系统唤醒事件；任务变化、功能关闭或 App 退出时会取消，异常中断遗留的事件会在 helper 下次启动时清理
- 定时触发后仅在重新读取和使用期间短暂阻止空闲睡眠，不唤醒显示器，也不会开启“防止系统睡眠”
- 系统自然唤醒或 App 下次启动时仍会立即补检；已经进入临期窗口且尚未过期时补试，否则按临期时间重新安排
- 只有已经读到具体凭证和过期时间时才会安排重试唤醒；每轮连续重试最多持续 5 分钟，后续普通额度刷新仍可重新尝试
- 当前没有可重置额度时不会消费次数，并会在本轮 5 分钟窗口内继续使用同一幂等键重试
- 服务端更新同一重置次数的过期时间后，会保留其幂等身份并按新时间重新安排
- 认证失效或确定的协议错误会暂停或停止当前任务，并在通知设置允许时通过系统通知说明

多台 Mac 同时开启时，每台设备独立调度，但会为相同 `creditId` 生成相同幂等键。最先成功的设备完成消费；其他设备收到已成功结果后停止，或者在刷新时发现凭证已经消失并静默停止。

成功后会发送“自动重置”通知。普通“额度已重置”通知来自额度窗口变化，因此两条通知可能同时出现。自动重置本身不依赖系统通知开关；通知关闭时仍会执行，只是不展示结果通知。

通知侧面板中的“自动重置通知”同时控制成功和失败通知，并为两者配置同一个音效。自动重置功能关闭时该项显示为关闭并置灰，保存的通知和音效选择不会被覆盖。

该设置只保存在当前 Mac，不通过 CloudKit 同步。

### 防止系统睡眠子选项

防止系统睡眠开关已开启且 CodexBar Hook 可用时，主开关行右侧可显示子选项按钮。没有符合条件的任务、CodexBarHelper 正在刷新、低电量保护生效或达到最长时间上限时，入口仍然保留；存在符合条件的任务但 CodexBarHelper 不可用时，入口会隐藏。

| 选项 | 默认值 | 可选值 |
| --- | --- | --- |
| 等待批准时保持防睡眠 | 关闭 | 开启或关闭 |
| 保持屏幕常亮 | 关闭 | 开启或关闭 |
| 最长防睡眠时间 | 12 小时 | 1, 2, 4, 8, 12, 24 小时或无限制 |
| 异常会话保护 | 1 小时 | 30 分钟, 1, 2, 4 小时 |
| 低电量保护 | 关闭 | 关闭或 5%, 10%, 15%, 20%, 25% |

没有内置电池的 Mac 不显示低电量保护。

完整说明见 [防止系统睡眠](sleep-prevention.md)

### 跨设备同步

- 只有 CodexBar Hook 已开启且 iCloud 可用时才能开启
- 首次开启会回填本机保留期内的每日 Hook 聚合
- 设置页显示同步状态和最近成功上传时间
- 关闭后停止网络同步，本机 Hook 数据仍然保留

完整说明见 [数据、同步与隐私](sync-data-privacy.md)

### 重建数据

- 日期选择器只允许选择原始 Hook 数据保留期内的日期
- 有原始事件的日期会显示数据标记
- 选择完整范围后才可执行重建
- 执行前会显示确认提示
- 完成后显示重建天数、事件数和跳过的无效行数
- 未完成的日期会在 Hook 可用时自动重试

## 关于页面

| 项目 | 作用 |
| --- | --- |
| Codex CLI | 展示全局 Codex CLI 的磁盘版本和路径 |
| Codex APP | 展示 ChatGPT App 或 Codex App 内置 CLI 的磁盘版本和路径 |
| 当前使用 | 标记当前 app-server 实际使用的 Codex 来源和运行版本 |
| CodexBar 版本 | 展示当前版本、更新状态和可用更新 |
| GitHub 项目 | 打开 CodexBar 项目页面 |
| 检查更新 | 手动触发 Sparkle 更新检查 |
| 退出 CodexBar | 先完成必要清理再退出 App |

磁盘中的 Codex 已更新但当前 app-server 还没有重连时，关于页面会同时提示新安装版本。

点击可执行文件路径可以复制完整路径。
