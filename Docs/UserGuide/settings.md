# 设置参考

右键或 Control 点击菜单栏图标并选择 `设置`，或按 `⌘,` 打开设置窗口。

设置窗口包含 `通用`，`高级` 和 `关于` 三个页面。

## 通用设置

| 设置 | 作用 | 默认或初始状态 |
| --- | --- | --- |
| 开机自动启动 | 通过 macOS 登录项自动启动 CodexBar | 跟随当前系统登录项状态 |
| 自动检查更新 | 由 Sparkle 定期检查可用更新 | 跟随 Sparkle 当前设置 |
| 菜单栏额度指示 | 在菜单栏图标旁显示所选额度窗口剩余比例 | 主额度 |
| 全局快捷键 | 在任意 App 中打开或关闭 CodexBar 主面板 | `⌘⇧W` |

### 菜单栏额度指示

- 可在当前 Codex 返回的额度窗口之间选择
- 关闭前会记住最后选择的窗口
- 再次开启时恢复上次选择
- 缓存额度会降低显示透明度

### 全局快捷键

- 录制结果至少需要两个修饰键
- `Command-Space` 和 `Command-Tab` 等系统保留组合不可使用
- 已被其他 App 占用的组合会提示冲突
- 可以清除快捷键
- 可以恢复默认值 `⌘⇧W`

## 高级设置

| 设置 | 作用 | 默认状态 |
| --- | --- | --- |
| CodexBar Hook | 安装并校验 Codex 事件 handler | 未安装时关闭 |
| 主面板任务中心 | 控制活动卡片和任务中心是否显示 | 开启，Hook 关闭时不可用 |
| 系统通知 | 控制 CodexBar 本地通知和任务触觉反馈 | 关闭 |
| 防止系统睡眠 | 根据实时 Codex 任务自动切换系统睡眠 | 关闭 |
| 跨设备同步 | 通过 iCloud 同步每日 Hook 聚合 | 关闭 |
| 重建数据 | 从所选日期的本机原始事件重新生成聚合 | 手动操作 |

### CodexBar Hook

开启后解锁实时任务，任务类通知，Hook 统计，防睡眠和跨设备同步。

开启和校验要求当前 app-server 为 `0.145.0` 或更高版本。

完整说明见 [实时任务与 CodexBar Hook](activity-and-hook.md)

### 主面板任务中心

关闭后，主面板不再显示活动卡片和任务中心入口。

这个设置不会关闭 Hook，不会停止 Hook 统计，通知或防睡眠。

Hook 关闭时该选项会显示为关闭并置灰，保存的选择不会被覆盖。

### 系统通知子选项

| 选项 | 默认值 | 其他可选值或说明 |
| --- | --- | --- |
| 任务完成通知 | 开启，1 分钟 | 最短时长可选 30 秒, 1, 2, 5 分钟 |
| 任务等待通知 | 开启 | 需要 CodexBar Hook |
| 额度预警通知 | 开启，10% | 阈值可选 5%, 10%, 25% |
| 额度重置通知 | 开启 | 只在观察到消耗后识别重置 |
| 重置临期通知 | 开启 | 提醒 7 天内到期的手动重置次数 |
| 低电量保护通知 | 开启 | 只有低电量保护实际可用时生效 |
| 防睡眠上限通知 | 开启 | 只有最长时间不是无限制时生效 |
| 任务触觉反馈 | 关闭 | 任务完成或等待批准时触发触摸板震动 |
| Codex TUI 通知 | 跟随 Codex 配置 | 独立于 CodexBar 通知 |

每类系统通知可以选择默认，静音，系统声音或 App 内置声音。

完整说明见 [通知与提醒](notifications.md)

### 防止系统睡眠子选项

| 选项 | 默认值 | 可选值 |
| --- | --- | --- |
| 等待批准时保持 | 关闭 | 开启或关闭 |
| 保持屏幕常亮 | 关闭 | 开启或关闭 |
| 最长防睡眠时间 | 12 小时 | 1, 2, 4, 8, 12, 24 小时或无限制 |
| 异常会话保护 | 1 小时 | 30 分钟, 1, 2, 4 小时 |
| 低电量保护 | 关闭 | 关闭或 5%, 10%, 15%, 20%, 25% |

没有内置电池的 Mac 不显示低电量保护。

完整说明见 [防止系统睡眠](sleep-prevention.md)

### 跨设备同步

- 只有 CodexBar Hook 已开启且 iCloud 可用时才能开启
- 首次开启会回填本机保留期内的每日 Hook 聚合
- 设置页显示同步状态和最近成功上传时间
- 关闭后停止网络同步，本机 Hook 数据仍然保留

完整说明见 [数据，同步与隐私](sync-data-privacy.md)

### 重建数据

- 日期选择器只允许选择原始 Hook 数据保留期内的日期
- 有原始事件的日期会显示数据标记
- 选择完整范围后才可执行重建
- 执行前会显示确认提示
- 完成后显示重建天数，事件数和跳过的无效行数
- 未完成的日期会在 Hook 可用时自动重试

## 关于页面

| 项目 | 作用 |
| --- | --- |
| Codex CLI | 展示全局 Codex CLI 的磁盘版本和路径 |
| Codex APP | 展示 ChatGPT App 或 Codex App 内置 CLI 的磁盘版本和路径 |
| 当前使用 | 标记当前 app-server 实际使用的 Codex 来源和运行版本 |
| CodexBar 版本 | 展示当前版本，更新状态和可用更新 |
| GitHub 项目 | 打开 CodexBar 项目页面 |
| 检查更新 | 手动触发 Sparkle 更新检查 |
| 退出 CodexBar | 先完成必要清理再退出 App |

磁盘中的 Codex 已更新但当前 app-server 还没有重连时，关于页面会同时提示新安装版本。

点击可执行文件路径可以复制完整路径。
