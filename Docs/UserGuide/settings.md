# 设置参考

简体中文 | [English](../en/UserGuide/settings.md)

右键或 Control 点击菜单栏图标并选择 `设置`，或按 `⌘,` 打开设置窗口。

## 通用设置

| 设置 | 作用 | 默认或初始状态 |
| --- | --- | --- |
| 主面板布局 | 调整账户、任务、额度、用量和状态的顺序与显隐 | 全部显示；Hook 关闭时任务区域关闭 |
| 动画效果 | 打开主面板时播放额度条和热力图动画 | 开启 |
| 开机自动启动 | 登录 Mac 后启动 CodexBar | 跟随系统登录项状态 |
| 自动检查更新 | 定期检查 CodexBar 更新 | 跟随当前更新设置 |
| 菜单栏额度指示 | 显示所选额度窗口的剩余比例 | 主额度 |
| 全局快捷键 | 在任意 App 中开关主面板 | `⌘⇧W` |

### 主面板布局

点击右侧选项按钮后，可拖动排序或切换区域开关，至少保留一个区域。使用 `⌘Z` 撤销、`⌘⇧Z` 重做。隐藏区域不会停止相关功能。

Hook 关闭时任务区域自动关闭，从关闭切换到开启时自动显示。开启后仍可手动隐藏任务区域，重启 App 会保留这一选择。如果任务是唯一可见区域，关闭 Hook 时账户区域会自动开启。

### 菜单栏额度指示

选择要显示的额度窗口。关闭后再开启，会恢复上次选择；数据变淡表示显示的是缓存额度。

### 全局快捷键

快捷键至少需要两个修饰键，不能使用 `Command-Space` 或 `Command-Tab`。组合已被占用时会提示冲突。可以清除快捷键或恢复默认值。

## 高级设置

| 设置 | 作用 | 默认状态 |
| --- | --- | --- |
| 代理 | 配置 CodexBar 的 Codex 服务连接代理 | 关闭 |
| [CodexBar Hook](activity-and-hook.md) | 启用实时任务和每日活动统计 | 未安装时关闭 |
| [系统通知](notifications.md) | 配置通知类型、阈值、音效和触觉反馈 | 总开关关闭 |
| 自动重置 | 提前使用即将过期的留存重置 | 关闭，提前 30 分钟 |
| [防止系统睡眠](sleep-prevention.md) | 在符合条件的任务运行时保持 Mac 唤醒 | 关闭 |
| [跨设备同步](sync-data-privacy.md) | 通过 iCloud 合并每日 Hook 统计 | 关闭 |
| [重建数据](sync-data-privacy.md#重建数据) | 重新计算所选日期的 Hook 统计 | 手动操作 |

### 代理

点击设置行打开配置，填写服务器地址和端口。支持 HTTP、HTTPS、域名、IPv4 和 IPv6；端口范围为 `1~65535`。开启身份验证后用户名必填，密码可留空。

HTTP 代理也能转发 HTTPS 请求。只有代理端口本身支持 TLS 时才选择 HTTPS，证书需有效。

- `测试连接` 检查尚未保存的配置，可取消，不会保存或启用代理
- `保存` 应用配置；首次保存后仍需打开设置行右侧开关
- `取消` 丢弃本次编辑
- `⋯ > 删除配置` 删除配置和密码并关闭代理，配置损坏时也可使用
- 关闭右侧开关会保留配置，便于下次启用

密码默认隐藏，鼠标移入密码框时显示。代理只影响 CodexBar 的 Codex 服务连接，密码以明文保存在本机。详情见 [数据、同步与隐私](sync-data-privacy.md)

### 自动重置

自动重置会在留存重置即将过期时自动使用它。每次开启均需确认；如提示后台服务需要授权，点击设置行下方的 `打开系统设置` 并允许 CodexBar 后台运行。

开启且 CodexBarHelper 获得批准后，点击右侧选项按钮设置临期时间：`15 分钟`、`30 分钟`、`1 小时`、`2 小时`、`4 小时` 或 `6 小时`，默认提前 `30 分钟`。

- 优先处理最早到期的可用留存重置，使用前重新检查登录和可用状态
- 可能短暂唤醒 Mac，但不点亮屏幕，也不会打开防睡眠开关
- 暂时失败时自动重试，每轮最多持续 5 分钟；后续刷新仍可再次尝试
- Mac 唤醒或 App 重新启动后，会补查尚未过期的留存重置
- 关闭功能或退出 App 会取消已安排的唤醒
- 多台 Mac 同时开启时，同一留存重置不会因重复尝试而多次消费

自动重置不依赖通知开关。结果提醒可在 [通知选项](notifications.md#自动重置通知) 中配置。该功能的设置只保存在当前 Mac。

## 关于页面

| 项目 | 操作或含义 |
| --- | --- |
| 来源 | 自动优先选择 Codex CLI，找不到时使用 ChatGPT App 或 Codex App 内置的 Codex，也可手动选择 |
| 重新建立连接 | 使用所选 Codex 来源重新连接，更新 Codex 后可用它立即切换到新版本 |
| Codex CLI / Codex APP | 查看检测到的版本，点击路径可复制 |
| 当前使用 | 当前连接所用的来源和版本 |
| 不可用（Codex 来源） | 之前使用或选择的来源已无法找到 |
| CodexBar Helper | 查看后台组件的安装与授权状态 |
| CodexBar 版本 / 检查更新 | 查看版本并检查可用更新 |
| GitHub 项目 | 打开项目页面 |
| 退出 CodexBar | 退出 App |

连接期间暂时不能切换来源。连接失败原因显示在版本区域底部，可据此排查或重新选择来源。

CodexBar Helper 状态始终显示在关于页面，不受自动重置和防睡眠开关影响：

| 状态 | 含义 |
| --- | --- |
| 未安装 | 尚未注册，且未发现组件或安装异常；首次使用时属于正常状态 |
| 未授权 | 已注册，仍需允许后台运行 |
| 已授权 | 系统已允许后台运行，当前未发现组件异常 |
| 不可用 | 组件缺失、配置或签名异常，或未注册且安装失败 |

发现组件异常时，即使之前已授权，也会显示“不可用”。处理方式见 [CodexBarHelper 无法注册](troubleshooting.md#codexbarhelper-无法注册)
