# 通知与提醒

简体中文 | [English](../en/UserGuide/notifications.md)

## 开启通知

1. 打开 `设置 > 高级`
2. 开启 `系统通知`
3. 在 macOS 授权窗口中允许通知
4. 点击右侧滑杆按钮配置各类通知

如果系统权限被拒绝，设置页会显示 `打开系统设置` 按钮。

通知总开关默认关闭，关闭时所有 CodexBar 系统通知和任务触觉反馈都停止。

## 通知类型

| 通知 | 触发条件 | 默认子开关 | 额外依赖 |
| --- | --- | --- | --- |
| 任务完成 | 任务完成且运行时长达到所选阈值 | 开启，1 分钟 | CodexBar Hook |
| 任务等待 | 任务进入等待用户批准状态 | 开启 | CodexBar Hook |
| 额度预警 | 可信额度首次跌到阈值或以下 | 开启，10% | 无 |
| 额度重置 | 已观察到消耗的额度窗口回到未消耗状态 | 开启 | 无 |
| 重置临期 | 留存重置进入过期前 7 天窗口 | 开启 | 存在可用留存重置 |
| 自动重置 | 自动重置明确返回成功或此前已成功 | 开启 | 自动重置开关、通知子开关和通知总开关 |
| 自动重置失败 | 认证失败导致暂停、协议错误导致停止，或本机明确观察到过期 | 与成功通知共用设置 | 自动重置开关、通知子开关和通知总开关 |
| 低电量保护 | 低电量保护成功恢复系统睡眠 | 开启 | 防睡眠和低电量保护 |
| 防睡眠上限 | 达到时长上限并成功恢复系统睡眠 | 开启 | 防睡眠和有限时长上限 |
| 异常会话保护 | 运行中任务超过静默阈值且候选仍有效 | 固定行为 | CodexBar Hook 和防睡眠主开关 |

异常会话保护没有独立通知开关，使用系统默认声音。

即使系统通知没有发送成功，已确认超时的异常任务仍会被隐藏并停止参与防睡眠。

匿名任务不触发任务完成通知、等待批准通知、异常会话保护通知或任务触觉反馈，但仍保留在活动卡片和任务中心中。

## 可选阈值

| 设置 | 可选值 |
| --- | --- |
| 任务完成最短时长 | 30 秒, 1 分钟, 2 分钟, 5 分钟 |
| 低额度阈值 | 5%, 10%, 25% |

额度预警只在剩余比例从阈值上方跨到阈值或以下时触发，不会在每次 60 秒刷新时重复发送。

同一额度重置周期内，退出并重新启动 CodexBar 也不会重复发送额度预警。

留存重置会在过期前 7, 6, 5, 4, 3, 2 和 1 天分别判断是否需要提醒。

## 自动重置通知

“自动重置”和“额度已重置”来自两个独立事实：

- “自动重置”说明本机自动调用收到 `reset` 或 `alreadyRedeemed`
- “额度已重置”说明额度窗口从已消费状态回到未消费状态

因此一次自动重置可能产生两条通知。它们不互相替代，也分别遵守各自的触发条件。

多台设备同时尝试时，明确收到成功结果的设备会发送自己的成功通知；只在刷新中看到凭证消失的设备不会通知，因为无法判断是手动使用、其他设备使用还是过期。

网络、超时和暂时服务错误只会在后台重试，不会每次通知。认证仍失败时当前任务暂停，后续可信快照确认认证恢复后继续；确定的协议错误会停止当前任务；本机明确观察到凭证过期时停止并通知。如果凭证直接从服务端明细消失，因为无法判断是手动使用、其他设备使用还是过期，本机会静默停止。

同一凭证的同一失败原因最多通知一次，不同失败原因可能分别通知。成功和失败通知共用“自动重置通知”子开关及音效。自动重置功能关闭时该选项不可用，重新开启后恢复此前的通知和音效选择。

## 通知音效

每类可配置通知都可以选择以下声音：

- 默认通知音
- 静音
- 当前 Mac 可用的系统提示音
- CodexBar 内置的 Modern 和 Material 提示音

非默认且非静音的声音可以在设置面板中试听。

如果已经保存的声音在当前 Mac 上不存在，CodexBar 会回退到默认通知音。

## 触觉反馈

开启 `任务触觉反馈` 后，任务完成或进入等待批准时会触发触摸板震动。

触觉反馈不依赖 macOS 通知授权，但仍然服从 CodexBar 的系统通知总开关和 CodexBar Hook 状态。

## Codex TUI 通知

`Codex TUI 通知` 修改的是 Codex 用户配置中的 `tui.notifications`

它与 CodexBar 本地通知相互独立，开启其中一个不会自动开启另一个。

## 通知交互

- CodexBar 位于前台时仍会显示通知横幅、通知列表项和声音
- 点击任意 CodexBar 通知会打开主面板
- 任务不再等待批准时，对应等待通知会从通知中心撤回
- 异常任务恢复进展或候选失效时，对应保护通知会从通知中心撤回
