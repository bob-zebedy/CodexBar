# 通知与提醒

## 开启通知

1. 打开 `设置 > 高级`
2. 开启 `系统通知`
3. 在 macOS 授权窗口中允许通知
4. 点击右侧滑杆按钮配置各类通知

如果系统权限被拒绝，设置页会显示 `打开系统设置` 按钮。

通知总开关默认关闭，关闭时所有 CodexBar 系统通知和任务触觉反馈都停止。

## 通知类型

| 通知 | 触发条件 | 默认子开关 | 额外依赖 |
| --- | --- | --- | --- |
| 任务完成 | 任务完成且运行时长达到所选阈值 | 开启，1 分钟 | CodexBar Hook |
| 任务等待 | 任务进入等待用户批准状态 | 开启 | CodexBar Hook |
| 额度预警 | 可信额度首次跌到阈值或以下 | 开启，10% | 无 |
| 额度重置 | 已观察到消耗的额度窗口回到未消耗状态 | 开启 | 无 |
| 重置临期 | 手动重置次数进入过期前 7 天窗口 | 开启 | 存在可用重置次数 |
| 低电量保护 | 低电量保护成功恢复系统睡眠 | 开启 | 防睡眠和低电量保护 |
| 防睡眠上限 | 达到时长上限并成功恢复系统睡眠 | 开启 | 防睡眠和有限时长上限 |
| 异常会话保护 | 运行中任务超过静默阈值且候选仍有效 | 固定行为 | CodexBar Hook 和防睡眠主开关 |

异常会话保护没有独立通知开关，使用系统默认声音。

即使系统通知没有发送成功，已确认超时的异常任务仍会被隐藏并停止参与防睡眠。

## 可选阈值

| 设置 | 可选值 |
| --- | --- |
| 任务完成最短时长 | 30 秒, 1 分钟, 2 分钟, 5 分钟 |
| 低额度阈值 | 5%, 10%, 25% |

额度预警只在剩余比例从阈值上方跨到阈值或以下时触发，不会在每次 60 秒刷新时重复发送。

手动重置次数会在过期前 7, 6, 5, 4, 3, 2 和 1 天分别判断是否需要提醒。

## 通知音效

每类可配置通知都可以选择以下声音：

- 默认通知音
- 静音
- 当前 Mac 可用的系统提示音
- CodexBar 内置的 Modern 和 Material 提示音

非默认且非静音的声音可以在设置面板中试听。

如果已经保存的声音在当前 Mac 上不存在，CodexBar 会回退到默认通知音。

## 触觉反馈

开启 `任务触觉反馈` 后，任务完成或进入等待批准时会触发触摸板震动。

触觉反馈不依赖 macOS 通知授权，但仍然服从 CodexBar 的系统通知总开关和 CodexBar Hook 状态。

## Codex TUI 通知

`Codex TUI 通知` 修改的是 Codex 用户配置中的 `tui.notifications`

它与 CodexBar 本地通知相互独立，开启其中一个不会自动开启另一个。

## 通知交互

- CodexBar 位于前台时仍会显示通知横幅，通知列表项和声音
- 点击任意 CodexBar 通知会打开主面板
- 任务不再等待批准时，对应等待通知会从通知中心撤回
- 异常任务恢复进展或候选失效时，对应保护通知会从通知中心撤回
