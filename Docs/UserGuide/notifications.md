# 通知与提醒

简体中文 | [English](../en/UserGuide/notifications.md)

## 开启通知

1. 打开 `设置 > 高级`
2. 开启 `系统通知`
3. 在 macOS 授权窗口中允许通知
4. 点击右侧滑杆按钮配置各类通知

如果系统权限被拒绝，设置页会显示 `打开系统设置` 按钮。

通知总开关默认关闭，关闭时所有 CodexBar 系统通知和任务触觉反馈都停止。

## 通知类型

| 通知 | 触发条件 | 默认子开关 | 额外依赖 |
| --- | --- | --- | --- |
| 任务完成 | 任务完成且运行时长达到所选阈值 | 开启，1 分钟 | CodexBar Hook |
| 任务等待 | 任务进入等待用户批准状态 | 开启 | CodexBar Hook |
| 额度预警 | 剩余额度达到预警阈值 | 开启，10% | 无 |
| 额度重置 | 已观察到消耗的额度窗口回到未消耗状态 | 开启 | 无 |
| 重置临期 | 留存重置进入过期前 7 天窗口 | 开启 | 存在可用留存重置 |
| 自动重置 | 自动重置明确返回成功或此前已成功 | 开启 | 自动重置开关、通知子开关和通知总开关 |
| 自动重置失败 | 认证失败导致暂停、协议错误导致停止，或本机明确观察到过期 | 与成功通知共用设置 | 自动重置开关、通知子开关和通知总开关 |
| 低电量保护 | 低电量保护成功恢复系统睡眠 | 开启 | 防睡眠和低电量保护 |
| 防睡眠上限 | 达到时长上限并成功恢复系统睡眠 | 开启 | 防睡眠和有限时长上限 |
| 异常会话保护 | 运行中任务持续无进展，达到保护阈值 | 固定行为 | CodexBar Hook 和防睡眠主开关 |

异常会话保护没有独立通知开关，使用系统默认声音。

即使系统通知没有发送成功，已确认超时的异常任务仍会被隐藏并停止参与防睡眠。

匿名任务不触发任务完成通知、等待批准通知、异常会话保护通知或任务触觉反馈，但仍保留在活动卡片和任务中心中。

## 可选阈值

| 设置 | 可选值 |
| --- | --- |
| 任务完成最短时长 | 30 秒, 1 分钟, 2 分钟, 5 分钟 |
| 低额度阈值 | 5%, 10%, 25% |

剩余额度降到阈值或以下时触发预警，启动后首次读到低额度也会提醒。额度需要有明确的重置时间，同一重置周期只提醒一次。

留存重置会在过期前 7, 6, 5, 4, 3, 2 和 1 天分别判断是否需要提醒。

## 自动重置通知

自动重置成功或因登录、设置错误、过期而停止时，会按通知设置提醒。暂时的网络失败只在后台重试。

一次自动重置可能同时产生“自动重置”和“额度已重置”两条通知：前者是操作结果，后者是额度变化。成功和失败共用“自动重置通知”开关及音效。

多台 Mac 同时尝试时，收到成功确认的设备会分别提醒；仅发现留存重置已消失的设备不提醒。同一留存重置的同一失败原因最多通知一次。

## 通知音效

每类可配置通知都可以选择以下声音：

- 默认通知音
- 静音
- 当前 Mac 可用的系统提示音
- CodexBar 内置的 Modern 和 Material 提示音

非默认且非静音的声音可以在设置面板中试听。

如果已经保存的声音在当前 Mac 上不存在，CodexBar 会回退到默认通知音。

## 触觉反馈

`任务触觉反馈` 默认关闭。开启后，任务完成或进入等待批准时会触发触摸板震动。

触觉反馈不依赖 macOS 通知授权，但仍然服从 CodexBar 的系统通知总开关和 CodexBar Hook 状态。

## Codex TUI 通知

此选项控制 Codex 自身的通知，与 CodexBar 通知相互独立。

## 通知交互

- CodexBar 位于前台时仍会显示通知横幅、通知列表项和声音
- 点击任意 CodexBar 通知会打开主面板
- 任务不再等待批准时，对应等待通知会从通知中心撤回
- 任务恢复进展或不再符合异常会话保护条件时，对应通知会从通知中心撤回
