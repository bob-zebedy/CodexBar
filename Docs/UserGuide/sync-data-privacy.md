# 数据、同步与隐私

简体中文 | [English](../en/UserGuide/sync-data-privacy.md)

## 跨设备同步

在 `设置 > 高级` 开启 `跨设备同步`，可以合并同一 iCloud 账户下多台 Mac 的每日 Hook 统计和 rollout Token 用量。需要先开启 CodexBar Hook，并登录可用的 iCloud 账户。

首次开启会上传本机保留期内的统计，之后自动同步变化。关闭同步会保留本机数据。

| 状态 | 含义 |
| --- | --- |
| 同步未开启 | 同步开关或 CodexBar Hook 已关闭 |
| 正在同步 | 正在传输数据 |
| 已同步 | 最近一轮同步成功 |
| 同步失败 | 网络、iCloud 账户或服务暂时不可用，稍后重试 |

主面板底部和设置页显示同步状态，设置页还显示最近成功上传时间。

## 哪些数据会上传

同步数据保存在你的 iCloud 私有数据库中，包括日期、每日事件和会话统计、项目显示名、模型名，以及用于区分设备和避免重复计数的标识。Token 历史另行同步脱敏轮次标识、必要时间和六项累计计数，用于跨设备去重后计算日汇总。

以下内容不参与同步：

- 原始 Hook 事件、会话和任务标识、完整工作目录
- 提问、Codex 回复、工具参数和输出
- Codex 账户、额度、app-server 账户用量和留存重置
- App 设置、代理配置和密码
- 日志、实时任务状态和异常会话保护记录

项目显示名会上传。若不希望将项目名存入 iCloud，请关闭跨设备同步。

## 本机数据

| 数据 | 内容与保留方式 |
| --- | --- |
| Hook 记录与每日统计 | 时间、事件、模型、工具、项目和任务标识等，保留 210 天；每日统计中的会话和轮次明细仅保留最近 3 天 |
| rollout Token 历史 | 哈希轮次标识、开始时间、累计计数和读取游标，保留 210 天；仍被子轮次引用的根时间一同保留 |
| 异常会话保护 | 无法直接还原的任务标识和时间，最长保留到最后进展后的 24 小时 |
| App 设置 | 保存在当前 Mac，包括代理配置；代理密码以明文保存 |
| 交互日志 | 最近 500 条 Codex 请求和响应，只在本次运行期间保留 |
| 后台服务状态 | 用于恢复睡眠设置和清理自动重置唤醒计划 |

CodexBar 读取本机 Codex 的任务状态和活动记录，但不保存提问、回复或工具内容，也不复制 Codex 登录凭据。

关闭代理会保留配置和密码；保存关闭身份验证的配置或选择 `删除配置` 时会删除密码。

## 历史 Token 回放

App 在历史统计刷新时自动读取本机 Codex 的 rollout，逐步补全保留期内的轮次用量，无需手动重建。每批保存用量和读取位置；退出后再次打开，会从保存的位置继续。追平历史后，后续刷新按读取位置处理追加内容。文件被替换或截断时会重新读取，同一线程轮次仍只计一次。

历史很多时可能需要多轮刷新才能补全。回放进度写入系统日志的 `workflow` 分类，读完当前检查范围内的文件后记录 `Rollout 回放完成`。这个状态表示本地回放进度，云端传输状态在同步区域查看。

日用量按根轮次开始时间和查看设备的本地时区归属。原始 rollout 已缺失或没有记录用量时，无法补出对应计数。

## 重建数据

统计异常时，可在 `设置 > 高级 > 重建数据` 选择日期范围并确认。可选范围为最近 210 天，有本机 Hook 记录或已发现 Token 轮次的日期会显示标记；未标记的日期也可以选择。

重建使用保留的本机 Hook 事件和 rollout，重新计算所选日期的活动统计与 Token 用量。Token 按根轮次开始日期归属，同一轮及其子线程不会重复累计。日期没有 Hook 事件时，也可以重建本机 rollout 中的 Token 数据。

重建在后台运行，可以继续使用主面板或关闭设置窗口。Token 按批读取，扫描完整成功后一次更新；取消或读取失败不会发布部分结果。退出 App 会停止本次重建，未完成的 Token 重建需要重新发起。完成后显示处理日期、活动记录和 Token 轮次数量。

开启同步时，重建结果会替换当前设备对应日期的活动统计，以及本机重新读到的 Token 轮次记录；其他轮次保留。重建可以降低 Token 计数；重新读到轮次但没有用量记录时，会清除该轮旧计数并同步到云端。本机已经缺失 rollout 的轮次保留已有统计，不会因此删除云端记录。账户信息、额度和 app-server 的账户用量不受影响。

## 网络与日志

| 网络访问 | 用途 |
| --- | --- |
| Codex 服务 | 获取账户、额度和用量，执行自动重置 |
| 更新服务 | 检查并下载 CodexBar 更新 |
| iCloud | 开启同步后传输每日 Hook 统计和会话 Token 数据 |

代理只用于 CodexBar 的 Codex 服务连接，不影响更新、iCloud 或其他 App。

交互日志可能包含账户和请求响应内容，退出 App 后清除。分享日志前，请检查其中是否有不希望公开的信息。
